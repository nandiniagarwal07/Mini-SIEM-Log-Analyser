🛡️ Mini SIEM - Log Analyzer

A lightweight, local Security Information and Event Management (SIEM) tool designed to analyze Linux authentication logs and identify security events.

## 👥 Team Members
* **Nandini** - Research & Log File Data Specialist
* **Palak** - Python Developer (Logic & Processing)
* **Ishika** - Documentation, Testing & Project Manager

## 🚀 Project Overview
This project reads real Linux `auth.log` files, parses system authentication activities, tracks user sessions, and generates automated security status alerts.

## 🛠️ Tools & Technologies Used
* **OS:** Kali Linux
* **Programming Language:** Python 3
* **Code Editor:** VS Code
* **Version Control:** GitHub
